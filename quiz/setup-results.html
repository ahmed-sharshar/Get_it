Instructor setup

Connect Quiz Results

Paste the Google Apps Script web-app URL to generate the student quiz link that records every submission in your Google Sheet.

1. Deploy the Google Apps Script

  1. Create a Google Sheet, then open Extensions → Apps Script.
  2. Paste the supplied Code.gs file into the editor.
  3. Run setupSheet once and approve the requested spreadsheet permission.
  4. Select Deploy → New deployment → Web app.
  5. Set Execute as to yourself and allow access to anyone who will take the quiz.
  6. Copy the deployed URL ending in /exec.

3. Download the class results

Open the Google Sheet at any time. Use File → Download → Microsoft Excel (.xlsx) or Comma-separated values (.csv).

The endpoint is stored only inside the generated link fragment. The quiz hosting service does not receive it, but students can still inspect it in their browser. This system is appropriate for practice and ordinary classroom quizzes, not a high-security examination.
